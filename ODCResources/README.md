# ODC Resources

Non-code resources for Forge users building with `OkfParsingLibrary` on
OutSystems Developer Cloud — things you copy/import into your own ODC
environment rather than build from.

- **`Prompts/`** — agent/LLM prompt files for use inside ODC (e.g. Agent
  Builder system prompts that call the `OKFParsingLibrary` external logic
  actions).
